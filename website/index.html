Загрузить JSON в каталог

Выбери JSON из приложения или TXT со ссылками VLESS/SOCKS5 (по одной на строку). Лимит 2 МБ и 1000 конфигураций. Создай Fine-grained token только для репозитория Scaner-proxy с разрешением Contents: Read and write. Вставленный токен используется только в памяти страницы и очищается после успешной загрузки. Не отправляй его никому. Содержимое JSON шифруется в браузере до отправки.

Ожидается JSON-файл. Cloudflare не используется.
